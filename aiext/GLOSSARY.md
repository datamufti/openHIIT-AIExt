# openHIIT-AIExt

An interval timer app, extended with plugins. These terms name what a user builds and runs.

## Language

**Timer**:
A saved, named workout definition: an ordered set of Intervals, optionally repeated.
_Avoid_: Workout (for the saved definition), schedule, routine

**Interval**:
One timed segment of a Timer, such as get-ready, work, rest, break, warmup or cooldown.
_Avoid_: Step, phase
